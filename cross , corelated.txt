

Cross Join 

1. Write a SQL query to display all possible combinations of employees and departments.


select e.department_id,department_name,employee_name
from departments d
cross join employees e


2. Write a SQL query to display all employees and all departments, including employees without departments and departments without employees.

select d.department_id,department_name,employee_id,employee_name
from departments d
left outer join employees e
on d.department_id = e.department_id
union
select d.department_id,department_name,employee_id,employee_name
from departments d
right outer join employees e
on d.department_id = e.department_id


3. Using two tables:
products
sizes
Write a SQL query to generate all possible product-size combinations.

select product_name,base_price,size
from sizes
cross join products

Correlated Subquery


1. Find guests who have made at least one booking.

   select g.guest_id,guest_name
from guests g
where exists (
	select 1 from bookings b where b.guest_id = g.guest_id)


2. Find guests who have never made a booking.

   select g.guest_id,guest_name
from guests g
where not exists (
	select 1 from bookings b where b.guest_id = g.guest_id)


3. Find guests who have made more than one booking.
select guest_id,guest_name from guests g
where (select count(*) from bookings b where g.guest_id = b.guest_id) > 1
  
4. Find guests whose average booking amount is greater than ₹10,000.
  
  select g.guest_id,guest_name,avg(total_amount)
from guests g
inner join bookings b
on g.guest_id = b.guest_id
group by b.guest_id
having avg(total_amount) > 10000
